没货管理

点一下款式 = 标成没货（打 ✕），再点一下 = 恢复有货。改完大约 1 分钟后客人菜单会更新。打开客人菜单

第一次使用：请输入 GitHub 密钥
  1. 在 GitHub 打开 Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access 选 Only select repositories →
  3. Permissions → Repository permissions → Contents 选 Read and write，生成后复制
密钥只存在这台手机的浏览器里，不会出现在网页上。
